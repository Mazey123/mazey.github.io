Качество

Как проверить, что приложение действительно прогрессивное

Главный инструмент проверки PWA — Lighthouse, встроенный в Chrome DevTools аудит от Google. Он анализирует страницу по нескольким категориям и указывает конкретные пункты, которые нужно исправить.

Категории аудита Lighthouse

Категории отчёта Lighthouse и типичные проблемы
Категория Что проверяет Типичная проблема
Performance Скорость загрузки и отклика интерфейса Слишком крупные изображения без srcset
Installable (PWA) Наличие манифеста, иконок и Service Worker Отсутствует поле start_url в манифесте
Best Practices Безопасность соединения, актуальные API Сайт частично загружается по HTTP
Accessibility Контраст, альтернативный текст, ARIA-атрибуты Изображения без атрибута alt
SEO Индексируемость и мета-теги Отсутствует мета-описание страницы

Инструменты для проверки

Chrome DevTools → Application

Вкладка «Application» показывает зарегистрированные Service Worker'ы, содержимое кэша и позволяет вручную имитировать отключение сети для проверки офлайн-режима.

Lighthouse CI

Консольная версия Lighthouse запускается командой npx lighthouse https://адрес-сайта --view и удобна для автоматической проверки при каждом деплое.

PWA Builder

Сервис Microsoft, который анализирует манифест и Service Worker сайта, а также помогает упаковать готовое PWA для публикации в Microsoft Store.

WebPageTest

Независимый сервис для замера реальной скорости загрузки с разных локаций и типов подключения — полезен для проверки, как приложение ведёт себя на медленном интернете.

Проверка кроссбраузерности

Помимо аудита PWA, важно вручную проверить сайт в последних версиях Chrome, Firefox и Safari — на разных операционных системах поведение установки и уведомлений отличается, как показано в таблице на странице «Технологии».

Полезные команды

  • npx lighthouse URL --view
  • npx http-server -S -C cert.pem
  • navigator.serviceWorker.getRegistrations()
