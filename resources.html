Ресурсы

Документация, статьи и инструменты по PWA

Подборка внешних материалов для тех, кто хочет углубиться в тему. Используйте фильтр, чтобы отобрать ресурсы нужного типа.

  • Документация

    MDN Web Docs — Progressive web apps

    Официальная документация Mozilla с описанием всех API, использующихся в PWA: Service Worker, Cache API, Manifest.

  • Документация

    web.dev / learn/pwa — Google

    Структурированный курс от команды Chrome с практическими примерами и разбором чек-листа установки.

  • Статья

    «Что такое Progressive Web Apps» — обзорная статья

    Популярное объяснение концепции PWA простыми словами, с примерами использования для бизнеса.

  • Статья

    Разбор кейсов внедрения PWA

    Серия материалов о результатах перехода на PWA у Twitter, Starbucks, Pinterest и других сервисов.

  • Инструмент

    Lighthouse

    Встроенный в Chrome DevTools аудит производительности, доступности и соответствия критериям PWA.

  • Инструмент

    PWA Builder

    Сервис для генерации манифеста, иконок и упаковки готового PWA под разные платформы.

  • Курс

    «Основы Service Worker» — практический курс

    Пошаговый онлайн-курс с заданиями по написанию собственного Service Worker и стратегий кэширования.
