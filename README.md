# PWA.Учебник

🔗 **Живой сайт (GitHub Pages):** https://mazey123.github.io/mazey.github.io/index.html

## О проекте

Учебный тематический сайт из 10 связанных страниц, посвящённый **прогрессивным веб-приложениям (Progressive Web Apps, PWA)**: что это такое, из каких технологий состоит, как устроена архитектура, какие есть плюсы и ограничения, как разрабатывать и тестировать своё PWA.

Проект выполнен в рамках учебного курса по фронтенд-разработке — практика семантической, валидной и адаптивной вёрстки с использованием CSS-фреймворка.

## Используемый стек

- **HTML5** — семантическая вёрстка (`header`, `nav`, `main`, `aside`, `footer`, `article`, `section`, `figure`, `details/summary`, `table`)
- **CSS-фреймворк: [Marx](https://mblode.github.io/marx/)** — классless CSS-фреймворк, стилизующий чистую семантическую разметку
- **Собственный CSS** (`css/style.css`) — дизайн-токены, БЭМ-компоненты (шапка, бургер-меню, сайдбар, карточки, таблицы, галерея, модальное окно, формы), 3 контрольные точки адаптивности (`<768px`, `≥768px`, `≥992px`)
- **JavaScript (нативный)** (`js/script.js`) — бургер-меню, модальное окно галереи, фильтрация карточек по категориям, демо-отправка формы, регистрация Service Worker
- Сайт сам является рабочим мини-PWA: подключён `manifest.json` и `sw.js` (офлайн-кэширование app shell)

## Как запустить локально

Сайт полностью статический, сборка не требуется.

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/Mazey123/mazey.github.io
   ```
2. Откройте `index.html` в браузере, либо запустите локальный сервер (рекомендуется для корректной работы Service Worker):
   ```bash
   npx http-server .
   ```
3. Перейдите по адресу, который выведет сервер (обычно `http://localhost:8080`).

## Деплой на GitHub Pages

1. Запушьте содержимое репозитория в ветку `main`.
2. В настройках репозитория откройте **Settings → Pages**.
3. Выберите источник **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните — через пару минут сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
5. Обновите ссылку на живой сайт в начале этого файла.

## Адаптивность

Вёрстка выполнена по подходу **Desktop-First** с последовательным сужением через `@media (max-width: 991px)` для планшетов/мобильных и явным разделением макета на 3 контрольные точки:

- **Мобильные (< 768px):** одна колонка, бургер-меню, сайдбар под основным контентом
- **Планшеты (≥ 768px):** двухколоночные карточки, бургер-меню сохраняется
- **Десктопы (≥ 992px):** полное горизонтальное меню без бургера, сайдбар — отдельная колонка рядом с контентом (`grid-template-columns`)
