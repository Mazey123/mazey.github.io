Как превратить обычный сайт в PWA

Ниже — минимальная последовательность шагов, которая превращает готовый сайт в устанавливаемое прогрессивное веб-приложение. Порядок шагов важен: манифест и Service Worker опираются на то, что сайт уже отдаётся по HTTPS.

  1. Разместите сайт по HTTPS

    Service Worker работает только на защищённом соединении (исключение — localhost во время разработки). Большинство хостингов, включая GitHub Pages, выдают HTTPS автоматически.

  2. Создайте файл манифеста

    Опишите название, иконки и цвет темы приложения в файле manifest.json и подключите его в <head> страницы:

    {
  "name": "PWA.Учебник",
  "short_name": "PWA",
  "start_url": "/index.html",
  "display": "standalone",
  "background_color": "#F4F6F9",
  "theme_color": "#1E3A5F",
  "icons": [
    { "src": "images/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "images/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
    <link rel="manifest" href="manifest.json">

  3. Зарегистрируйте Service Worker

    В основном JavaScript-файле сайта добавьте регистрацию фонового скрипта:

    if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/sw.js')
    .then(() => console.log('Service Worker зарегистрирован'))
    .catch((err) => console.error('Ошибка регистрации', err));
}

  4. Опишите стратегию кэширования

    Внутри sw.js определите, какие файлы кэшировать при установке и как отвечать на запросы:

    const CACHE_NAME = 'app-shell-v1';
const ASSETS = ['/', '/css/style.css', '/js/script.js'];

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(ASSETS))
  );
});

self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((cached) => cached || fetch(event.request))
  );
});

  5. Подготовьте иконки и заставку

    Добавьте иконки нескольких размеров (минимум 192×192 и 512×512 пикселей) — они используются при установке на разные устройства и для генерации экрана загрузки.

  6. Настройте push-уведомления (опционально)

    Для повторного вовлечения пользователей подключите Push API и Notifications API — это потребует серверной части для рассылки сообщений через сервис push-уведомлений браузера.

  7. Проверьте установку и запуск офлайн

    Отключите сеть в инструментах разработчика и убедитесь, что приложение всё ещё открывается. Подробнее о проверке — на странице «Тестирование».
