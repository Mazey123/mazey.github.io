## Как получить обе ссылки

1. Создайте новый репозиторий на GitHub и загрузите в него все файлы из этого архива (см. `README.md` — там есть команды и структура проекта).
2. В репозитории откройте **Settings → Pages**, выберите ветку `main` и папку `/(root)`, сохраните.
3. Через 1–2 минуты GitHub покажет ссылку на живой сайт вида `https://<логин>.github.io/<репозиторий>/` — скопируйте её сюда и в верхнюю строку `README.md`.
4. Ссылку на сам репозиторий скопируйте из адресной строки браузера (или кнопки **Code → Copy**).
